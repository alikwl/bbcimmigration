# static-site-architect

Use this skill when creating or restructuring the static website project.

## Rules
- Read `PRD.md` first.
- Prefer Astro static output for GitHub Pages.
- Keep pages data-driven where possible.
- Do not copy competitor copyrighted text/images.
- Keep project beginner-friendly and easy to deploy.

## Output
- Astro project structure
- Layouts/components/data files
- Working build scripts
- README commands
