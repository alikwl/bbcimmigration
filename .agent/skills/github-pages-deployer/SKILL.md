# github-pages-deployer

Use this skill to deploy the static site to GitHub Pages.

## Rules
- Add GitHub Actions workflow for Astro.
- Site must build with `npm run build`.
- Output directory should be `dist`.
- Support project repo deployment and custom domain later.
- Add clear README deployment steps.

## Acceptance
- Workflow file exists.
- Build passes.
- GitHub Pages can publish from Actions.
