# content-structure-builder

Use this skill for service data, page hierarchy, and page templates.

## Rules
- Use original rewritten content.
- Keep all service slugs from PRD.
- Service pages must include: intro, who it is for, requirements, documents, process, FAQ, CTA, related services.
- Add disclaimers for immigration/legal information.

- `src/data/services.json`
- `src/data/faqs.json`
- `src/data/site.ts`
