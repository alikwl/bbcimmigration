# ui-recreation-designer

Use this skill to recreate the visual experience safely.

## Rules
- Recreate layout patterns, not exact copyrighted design.
- Use modern immigration consultancy style: navy/blue, white, gold accent.
- Build responsive header, dropdown, mobile hamburger, CTA sections, cards.
- Accessibility first: aria labels, contrast, focus states, keyboard nav.
- No broken layouts on mobile.

## Checklist
- Header/footer complete
- Hero responsive
- Cards responsive
- Forms usable
- No horizontal scroll
