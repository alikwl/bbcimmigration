# static-form-integration

Use this skill when adding forms to a GitHub Pages/static website.

## Rules
- GitHub Pages cannot run backend/PHP form handlers.
- Use external endpoints: n8n webhook, Formspree, Getform, Basin, Google Forms, etc.
- Add client-side validation.
- Add consent checkbox.
- Capture UTM and page source hidden fields.
- Show clear success/error messages.

## Required Fields
Full name, email, phone/WhatsApp, service, message, consent.
