# asset-collector-optimizer

Use this skill for images/icons and asset organization.

## Rules
- Do not use copied competitor images unless written permission exists.
- Use licensed assets or placeholders.
- Create `public/assets/images/services/` structure.
- Add alt text for every image.
- Prefer webp/jpg optimized sizes.
- Create `ASSET_MANIFEST.md` with file names, purpose, source/license, replacement notes.

## If Permission Exists
Assets may be collected from the source website only if the user confirms ownership/permission.
